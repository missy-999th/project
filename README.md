\## Descripción



Este repositorio fue creado para practicar los comandos básicos de Git y GitHub.



\*\*Git\*\* permite controlar las versiones de un proyecto.



\*GitHub\* permite almacenar y compartir repositorios en línea.



\## Comandos utilizados



1\. git init

2\. git status

3\. git add .

4\. git commit

5\. git push

\## Comandos principales



| Comando | Función |

| --- | --- |

| `git status` | Revisa los cambios |

| `git add .` | Prepara los archivos |

| `git commit` | Guarda los cambios |

| `git log` | Muestra el historial |

| `git push` | Publica los cambios en GitHub |
